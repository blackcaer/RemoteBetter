# RemoteBetter

**RemoteBetter** automates Steam trades and manages in-game item deposits on Rust gambling sites. It interacts with gambling site's Coinflip game mode, scraping trade offers and processing deposits in real-time.

It's main use-case was joining Conflips with given intervals while giving away as low-value items as possible while also ensuring that created coinflip can be taxed (as can be seen in select_items_taxed function). 

- Handles Steam trade offers for Rust skins.
- Scrapes and interacts with the Coinflip game mode.
- Processes skin deposits.
- Implements robust error checking and retries.

No support or proper documentation is provided since it was project for personal use only and I didn't think of publishing it at the time.
